从一句话，到可继续的工作区

新对话绑定项目目录。文件、附件与项目记忆跟随工作区，而不是丢失在聊天记录里。

02 / EXECUTION

工具调用有记录

参数、耗时、退出码、完整返回与文件行变化都能展开查看。

03 / MEMORY

项目记忆可控制

读写、只读、关闭三态。记忆写进 .NexcoreWork，可查看、修正和删除。

执行不是黑盒。

模型说“完成了”不算完成。有没有调用工具、写了哪个文件、改了多少行、为什么停下，都由运行时留下证据。
