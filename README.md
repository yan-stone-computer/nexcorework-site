# NexcoreWork 官网

零依赖静态官网，展示 NexcoreWork 的本地优先架构、可核验执行过程、免费模型 Auto、工具与知识能力。

## 本地预览

```powershell
python -m http.server 8096
```

打开 `http://127.0.0.1:8096`。

## 下载

官网按钮指向 GitHub Releases 中的 Windows 安装包。当前版本为 `0.1.0-alpha.1`。

## 素材

- 产品界面为 NexcoreWork 真实截图。
- 首屏桌面背景由本机 ComfyUI + Qwen-Image-2.1 生成，仅作氛围背景，不代替产品界面。
- 页面无外部字体和前端依赖，适合直接部署到 GitHub Pages。
